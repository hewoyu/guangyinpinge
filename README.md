## 核心机制

- **番茄钟**：25|5 模式（25 分钟专注/5 分钟休息），右栏大数字倒计时（无进度环——截图实锤）
- **碎片掉落**：专注中每 2-5 分钟随机掉落 1 块（飞入动画），底部提示条结算文案
- **144 块咬合拼图**：Jigsaw 引擎（seed 确定性凸凹边表），未收集格=米白空白咬合块
- **旅程系统**：完成专注 → 结算信（"这是你的第N趟旅程…"）→ 纸飞机开启下一段
- **景笺货币**：成就领取 → 景笺 → 窗景商店兑换窗外风景（v5-29 已落地）
- **按日统计**：history 记录每日分钟/碎片 → 热力图与柱图数据源

## v5/v6 新功能

- **拼图模式 + 自动拼**：玩法页双模式——专注收集可视化 / 拼图模式（碎片拖拽吸附正确格位点亮，格位低亮度提示目标）；「自动拼」按行主序自动吸附全部已收集碎片（scripts/puzzle_board.gd）
- **明信片完成链路**：拼图全部拼上 → 会动的明信片（显影动画 + 旅程祝福文案）→ 旅程结算信 → 纸飞机开启下一段旅程（scenes/postcard.tscn、journey_letter.tscn）
- **窗景商店**：成就领取景笺货币 → 兑换窗外风景（春樱雨/冬雪原/黄昏海港/极夜极光），兑换后永久可用，书房窗户实时换景（achievements_page v5-29、GameState.WINDOW_VIEWS）
- **待办管理 + 数据管理页**：统计页四标签（专注概览/热力图/数据管理/待办管理）；待办页含 12 卡统计棋盘、列表/归档/搜索、清除数据；数据源统一 TodoData（class_name，user://todo.json）
- **9 幅图库（含壁纸）**：春日野餐/星空下的家/海边灯塔 3 幅手绘 + 6 幅必应每日精选风光壁纸（1:1 裁切、拼图友好度 Top6 筛选），拼图选择网格切换
- **成就四分类**：次数/天数/拼图/时长四类成就 + 连续专注 streak（开机测试/三次不是巧合/三日之约…），领取得景笺
- **玩家模拟测试**：tests/player_sim.gd 以真实按钮信号驱动完整游玩流（专注→掉碎片→拼图→明信片→结算），逐步记录体验输出
